# 📋 Что добавлено в проект UDS Editor

Этот документ описывает все новые функции, добавленные в редактор OSM моделей, и объясняет, как ими пользоваться.

---

## 🪑 1. Лавочки / Скамейки (`amenity=bench`)

### Что добавлено
- Новый пресет **Лавочка / Скамья** в панели выбора объектов
- Поле **Материал лавочки**: дерево, металл, бетон, камень, пластик, композит, рециклированный пластик
- Поле **Ссылка на фото объекта** (OSM тег `image`)
- Поле **Сайт объекта** (OSM тег `website`)

### Где искать
В панели выбора объектов введите поиск: `лавочка`, `скамейка` или `bench`

---

## 🏛️ 2. Беседки (`leisure=gazebo`)

### Что добавлено
- Новый пресет **Беседка** в панели выбора объектов
- Поле **Тип беседки**: деревянная, металлическая, каменная, кирпичная, другая

- Поле **Сайт объекта** (OSM тег `website`)

В панели выбора объектов введите поиск: `беседка`, `альтанка` или `gazebo`

## 🚌 3. Остановки по типам (`highway=bus_stop`)

### Что добавлено
Вместо одной общей остановки теперь **8 отдельных пресетов**:

| Пресет | Описание |
|--------|----------|
| Остановка (базовая) | Простая остановка без дополнительных атрибутов |
| Остановка с грибком | Табличка на специальной крышке (грибок) |
| Остановка с отоплением | Тёплая остановка с отоплением |
| Остановка с баком для мусора | Есть урна для мусора |
| Остановка с грибком и отоплением | Комбинированный вариант |
| Остановка с грибком и баком | Комбинированный вариант |
| Остановка с отоплением и баком | Комбинированный вариант |
| Остановка со всем | Грибок + отопление + бак |

### Дополнительные поля
Все остановки имеют поля:
- Тип таблички (грибок / столб / без таблички)
- Отопление (да / нет)
- Бак для мусора (да / нет)
- Ссылка на фото объекта
- Сайт объекта

### Где искать
В панели выбора объектов введите поиск: `остановка`, `автобус` или `bus_stop`

## 📍 5. Запись GPS-трека

### Что добавлено
- Новый режим записи GPS-трека через браузерное API геолокации
- Кнопка на верхней панели инструментов
- Горячая клавиша: `G`
- Индикатор количества записанных точек на кнопке

### Как пользоваться

1. Нажмите кнопку GPS-трека на верхней панели (или клавишу `G`)
2. Дождитесь запроса доступа к геолокации и разрешите его
3. Будут записываться точки вашего перемещения как узлы OSM, соединённые в линию
4. Минимальное расстояние между точками: 5 метров (чтобы не создавать лишние точки)
5. Нажмите кнопку повторно, чтобы остановить запись
6. Трек сохранится как линия с тегами: `type=gps_track`, дата создания и количество точек

### Индикация
- Кнопка меняет цвет и показывает количество точек во время записи
- Всплывающее уведомление при начале и окончании записи
- Клавиша `G` переключает запись включить/выключить

## 🚀 Как запустить и попробовать

### Предварительные требования
- Node.js (версия 22+)
- Интернет-соединение (для загрузки снимков карт)

### Пошаговая инструкция

**1. Откройте Командную строку (cmd.exe) — не PowerShell:**

```cmd
cd c:\Users\yushi\Downloads\uds-editor
```

**2. Установите зависимости:**

```cmd
npm install --legacy-peer-deps
```

**3. Соберите проект:**

```cmd
npm run build
npm run dist
```

**4. Запустите сервер разработки:**

```cmd
npm start
```

**5. Откройте в браузере:**

```
http://localhost:8080
```

## 🗺️ Как выбрать снимки карт

После открытия редактора:

1. Нажмите кнопку слоёв (иконка карты) в правой панели
2. Выберите источник снимков (Bing, Maxar, Esri или другой подходящий для вашего региона)
3. Если нужно — нажмите "Добавить источник" и укажите URL тайлов

## 📝 Примеры тегов OSM

```
amenity=bench

image=https://example.com/photo.jpg

```

### Беседка
```
leisure=gazebo
```

```
highway=bus_stop

```

### GPS-трек
```
type=gps_track
created=2026-11-10T15:00:00Z
points=145
```

## ⚠️ Известные ограничения

1. Запись GPS-трека требует доступа к геолокации браузера
2. Для работы со снимками карт нужно выбрать источник в панели слоёв
3. Все изменения сохраняются в локальной сессии — для отправки в OSM используйте функцию сохранения
4. При первом запуске могут появиться предупреждения о пропущенных переводах — они не влияют на работу

## 🛠️ Техническая реализация

- Пресеты добавлены в `modules/presets/custom.ts` через функцию `presetsWithCustom()`
- Новые поля используют тип `combo` (выпадающий список) и `text` (текстовое поле)
- GPS-трек реализован через `navigator.geolocation.watchPosition()`
- Точки трека создаются как OSM узлы, соединяются в линию (way)
- Кнопка на панели использует клавиатурную комбинацию `G` для быстрого доступа
