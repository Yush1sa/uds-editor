# 🗺️ UDS Editor — Редактор OSM моделей

Проект основан на [openstreetmap/iD](https://github.com/openstreetmap/iD) — дружелюбном редакторе для OpenStreetMap.

UDS Editor расширяет базовый iD инструментами для редактирования объектов инфраструктуры: лавочки, беседки, остановки公共 транспорта, запись GPS-треков и привязка фото к объектам.

---

## ✨ Что нового в этой версии

### 1. 🪑 Лавочки / скамейки (`amenity=bench`)
Пресет лавочки уже存在 в базе OSM. К нему добавлены новые поля:

| Поле | OSM-тег | Описание |
|------|---------|----------|
| Материал лавочки | `material` | дерево, металл, бетон, камень, пластик, композит, рециклированный пластик |
| Ссылка на фото | `image` | Прямая ссылка на фото объекта |
| Сайт объекта | `website` | Веб-сайт объекта |

**Поиск:** введите `лавочка`, `скамейка` или `bench` в панели выбора объектов.

### 2. 🏛️ Беседки (`leisure=gazebo`)
Новый пресет для беседок:

| Поле | OSM-тег | Описание |
|------|---------|----------|
| Тип беседки | `gazebo:type` | деревянная, металлическая, каменная, кирпичная, другая |
| Ссылка на фото | `image` | Прямая ссылка на фото объекта |
| Сайт объекта | `website` | Веб-сайт объекта |

**Поиск:** `беседка`, `альтанка`, `gazebo`.

### 3. 🚌 Остановки (`highway=bus_stop`)
Пресет остановки уже存在 в базе OSM. К нему добавлены поля для уточнения типа:

| Поле | OSM-тег | Варианты |
|------|---------|----------|
| Тип таблички | `bus_stop:sign` | грибок, столб, без таблички |
| Отопление | `heating` | да / нет |
| Бак для мусора | `waste_basket` | да / нет |
| Ссылка на фото | `image` | Ссылка на фото |
| Сайт объекта | `website` | Сайт объекта |

**Поиск:** `остановка`, `автобус`, `bus_stop`.

### 4. 📷 Фото и ссылки на объекты
Поля `image` и `website` добавлены к лавочкам, беседкам и остановкам. Позволяют прикреплять ссылки на реальные фотографии и веб-сайты объектов.

### 5. 📍 Запись GPS-трека
Новый режим записи траектории движения:

- **Кнопка** на верхней панели инструментов
- **Горячая клавиша:** `G`
- Запись через браузерное API геолокации (`navigator.geolocation.watchPosition`)
- Точки создаются как узлы OSM, соединяются в линию (way)
- Минимальное расстояние между точками: 5 метров
- По завершении линия получает теги: `type=gps_track`, дата создания, количество точек
- Индикатор записи на кнопке и всплывающие уведомления

## 🚀 Быстрый старт

### Требования
- Node.js >= 22
- Интернет-соединение (для снимков карт)

### Установка и запуск

Откройте **Командную строку** (cmd.exe, не PowerShell):

```cmd
cd c:\Users\yushi\Downloads\uds-editor
npm install --legacy-peer-deps
npm run build
npm run dist
npm start
```

Откройте браузер: **http://localhost:8080**

### Выбор снимков карт
1. Нажмите кнопку слоёв (иконка карты) в правой панели
2. Выберите источник снимков (Bing, Maxar, Esri и др.)
3. Или добавьте свой источник через URL тайлов

## 📝 Примеры тегов OSM

### Лавочка
```text
amenity=bench
material=wood
image=https://example.com/photo.jpg
website=https://example.com
```

### Беседка
```text
leisure=gazebo
gazebo:type=wooden
image=https://example.com/photo.jpg
```

### Остановка с грибком, отоплением и баком
```text
highway=bus_stop
bus_stop:sign=mushroom
heating=yes
waste_basket=yes
image=https://example.com/photo.jpg
```

### GPS-трек
```text
type=gps_track
created=2026-11-10T15:00:00Z
points=145
```

## ⚠️ Известные ограничения

1. GPS-трек требует доступа к геолокации браузера
2. Для снимков карт нужно выбрать источник в панели слоёв
3. Изменения сохраняются локально; для отправки в OSM используйте функцию сохранения
4. Предупреждения о пропущенных переводах не влияют на работу

---

## 🛠️ Техническая детали

- Пресеты расширяются через `modules/presets/custom.ts` функцией `presetsWithCustom()`
- Существующие пресеты OSM (`amenity/bench`, `highway/bus_stop`) не дублируются, а расширяются новыми полями
- Новый пресет беседки (`leisure=gazebo`) добавляется как кастомный
- GPS-тrek реализован через `navigator.geolocation.watchPosition()`
- Точки трека сохраняются как OSM узлы, соединённые в линию (way)
- Кнопка GPS-трека использует клавиатурную комбинацию `G`
